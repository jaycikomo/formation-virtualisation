Architecture pédagogique retenue

Le format reprend les éléments qui reviennent dans les parcours techniques professionnels : fondamentaux, déploiement, administration, sécurité, sauvegarde/restauration et dépannage, avec des travaux pratiques. Pour CIEL, on les transforme en microcapsules à trois niveaux.

Niveau 1 · Comprendrevocabulaire, architecture, choix de technologie, premiers gestes.
Niveau 2 · Mettre en œuvreinstallation, configuration, réseau, stockage, services.
Niveau 3 · Administrersécurité, sauvegarde, restauration, diagnostic, optimisation.
Transposition CIELchaque parcours se termine par une activité directement adaptable aux élèves.

Je crée une ressource : un Lab pour mes élèves

La formation se termine par une production concrète. Chaque participant choisit les briques qu'il a réellement travaillées et construit une ressource pédagogique réutilisable pour ses élèves de Bac Pro CIEL.

Quatre exemples de Labs élèves

Ces exemples servent de point de départ. Ils montrent qu'un Lab final peut être très différent selon le parcours choisi.

EXEMPLE 01 · AD

Mini-domaine CIEL

Créer un domaine isolé et intégrer un poste client.

  • DC01 : 192.168.10.10
  • PC01 : 192.168.10.21
  • Domaine : ciel.lan
  • Panne : DNS client incorrect
  • Retour : snapshot domaine-ok
EXEMPLE 02 · DOCKER

Service Web conteneurisé

Déployer un site Nginx, comprendre image, port et volume.

  • Debian + Docker
  • Nginx sur port 8080
  • Réseau Docker + compose.yaml
  • Portainer + Uptime Kuma
  • Panne : mauvais port ou mauvais réseau
  • Retour : compose.yaml + volumes
EXEMPLE 03 · PROXMOX

Serveur de Lab isolé

Déployer deux VM sur un bridge de laboratoire.

  • Proxmox physique
  • vmbr-LAB isolé
  • 1 Linux + 1 client
  • Panne : mauvaise vNIC
  • Retour : sauvegarde/clone
EXEMPLE 04 · RÉSEAU

Panne mystère

Faire diagnostiquer une rupture de communication entre deux VM.

  • 2 VM sur LAN interne
  • Plan IPv4 fourni
  • Erreur volontaire DNS/IP
  • Méthode de diagnostic
  • Preuve : service joignable
